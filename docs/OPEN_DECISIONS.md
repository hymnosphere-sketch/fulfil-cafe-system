# Open Decisions

The project leader approved a single Android tablet, a web-first and local-first inventory PWA, the Modern Café visual direction, and the documented stack. Frontend foundation and the fictional first functional slice can proceed. Production business policies below remain pending. The technical designs are proposals for review and implementation.

**A** gates the affected core implementation. **B** can be decided during development. **C** gates protected deployment or an optional deployment feature. **D** applies only to conditional Stage 2. Team and café approvals apply to the relevant part of each decision. Work package IDs are defined in [Team Delegation](TEAM_DELEGATION.md), and requirements are defined in [Requirements](REQUIREMENTS.md).
